## Description
After performing a second-tick [[crawlturncancel]], there is a window exactly 4 ticks later to input down, forwards and jump, to jump 119.4 units / ~6 tiles into the air.

## Notes
The start of this move doesn't set jump-boost so you can gain extra height by having js so the 1 tick it takes the jump to activate and overwrite any js gives extra height, using this with 6[[jumpstore|js]] can reach up to 168 units / 8.4 tiles , and 191 units / 9.5 tiles with 8[[jumpstore|js]].

Slugcat ends this move in the crouch state, so an additional up input to [[airorient]] is required to [[ledgepullup]] an additional 2 tiles.
