## Description
By doing a charge pounce, and immediately after the start of the tech pressing up and jump again, you can cause the slugcat to pounce midair, giving more distance

## Notes


## Inputs
High variation start from crouched position
```
J~21
FU~1
FJ~2
FDJ~4
FU~1
F~1+
```
Due to a bug with the games input handling the first tick of `FDJ` get's overwritten to `DJ` which slightly decreases distance. This tech is the only known case of the this happening.

Horizontal variation start from crouched position
```
J~21
FU~3
FDJ~3
FUJ~3
F~1+
```

Low variation start from crouched position
```
J~21
FUJ~2
FU~1
FD~2
FJ~6
F~1+
```
