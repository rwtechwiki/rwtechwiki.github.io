## Description
By doing a crawl turn cancel followed by repeating 2 tick forwards and backwards inputs without any neutral inputs it's possible to fly by abusing an oversight in the [[crawlturn]] animation. By getting [[jumpstore|jumpstorage]] and not letting go of jump it's possible to increase the starting speed of the flight.

## Notes

## Inputs
Starting from a crouched position inputs:
```
B~1
BU~4
F~3
<
B~2
F~2
>repeat
```

Starting from a standing position the 6js variation inputs:
```
DJ~2
J~10
BJ~1
BUJ~4
FJ~3
<
B~2
F~2
>repeat
```
